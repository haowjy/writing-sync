# writing-sync

Mars source package of destination-sync skills for writing projects.

`skills/drive-sync` is the current skill: selected local files to a remote
reading copy (Google Drive/Docs) and back. Other destinations (Royal Road and
similar) belong here later as **separate skills**, not as extra backends inside
`drive-sync`.

This package is operational (CLI + workflow resources), not craft. Do not add
these skills to `creative-writing-skills` `cw/` or `GENERATED_SKILLS`.

```bash
meridian mars check
```
